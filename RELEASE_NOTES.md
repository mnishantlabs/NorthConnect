# 🚀 NorthConnect v2.0.0 — Major Architectural Overhaul & Feature Suite

Welcome to the brand new **NorthConnect**! This release marks a complete, ground-up rewrite from Python/Tkinter to a high-performance **Electron 30 + TypeScript + React 18 + Vite** architecture.

---

## 🌟 What's New

### 🎧 YouTube & Spotify Real-Time Voice Streaming
- **YouTube Music & Spotify Search**: Search millions of tracks and artists directly within the app.
- **Direct Link Playback**: Paste any YouTube, YouTube Music, or Spotify URL to stream directly into Discord voice channels.
- **Zero Disk Writes**: Powered by an in-memory decoding pipeline piping 48,000 Hz 16-bit raw stereo PCM directly to @discordjs/voice gateways.
- **Broadcast Target Routing**: Stream audio across all connected tokens or select an individual target token.

### 🎛️ Compact Card Grid & Media Player
- **Sleek Card Grid Layout**: Saved audio files and online bookmarks render in a compact card grid with duration overlays and format badges.
- **Local PC Preview**: Audition audio files locally through your PC speakers (Headphones button) before broadcasting into Discord.
- **Soundboard Presets**: Trigger customizable sound effects (Gaming, Memes, Anime, Reactions, SFX) with volume boost up to 200%.
- **View Mode Switcher**: Toggle between the compact card grid and classic table views anytime.

### 👥 Multi-Account Gateway Engine & Token Extractor
- **Multi-Token Dashboard**: Manage, validate, and monitor dozens of Discord accounts simultaneously with avatar rendering and status tags.
- **Companion Chrome Extension**: Shipped with the token extractor extension in xtensions/ for 1-click token harvesting from web sessions.
- **Live Server Controls**: Inspect server channels & active members, watch screen shares, and safely leave servers with confirmation dialogs.
- **Encrypted Local Storage**: Zero telemetry, zero external tracking, 100% local encrypted storage.

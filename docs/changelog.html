v1.0.0 · MAJOR REFACTOR

TypeScript & Electron Ground-Up Overhaul

  • Full Architecture Migration: Rebuilt the legacy desktop UI into high-performance TypeScript + Electron 30 + React 18 + Vite.
  • YouTube & Spotify Streaming: Real-time streaming into Discord voice channels with in-memory decoding and zero disk footprint.
  • Compact Grid Media Player: Saved tracks and online bookmarks render in a compact card grid layout with instant PC headphones preview and format indicators.
  • Broadcast Target Control: Route music playback across all active tokens or send to individual connected tokens.
  • Interactive Soundboard: Multi-category sound triggers with volume boost up to 200%.
  • Token Extractor Chrome Extension: Integrated companion browser extension for automatic token discovery and sync.
  • Voice Server Controls: Screen share viewer, mute/deafen controls, and leave server confirmation modal.
NorthConnect · Independent tool · Not affiliated with Discord Inc.

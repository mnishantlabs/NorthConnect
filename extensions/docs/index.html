why it's useful

vault

personal vault

group, favorite, tag and search your saved sessions. add manually or from the active session.

switch

one-click switch

apply a saved session to a discord.com tab and reload — fast account rotation.

check

verify tokens

check individual or all saved tokens right from the popup.

copy

copy & export

copy a token in one click, or export a json backup of everything.

info

account details

see user id, status, joined date, badges and notes for each session.

local

100% local

data lives in browser storage only. no accounts, no telemetry, no servers.

browser support

mv3

chrome & chromium

chrome, edge, brave, opera, arc — all chromium-based browsers load the mv3 chrome package the same way.

mv2

firefox

firefox loads it as a temporary add-on (stays active until you close firefox). the firefox zip package is ready to go.

heads up: this extension manages session tokens, which may violate discord's terms of service. use it for your own personal, low-volume use, at your own risk. it is not affiliated with discord.

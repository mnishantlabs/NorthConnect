installation guide

setup

pick your browser below and follow the steps. the whole process takes about two minutes.

01

download

download the chrome .zip from the download page and extract it somewhere permanent — e.g. your documents folder.

02

open extensions page

open chrome://extensions in your address bar.

03

enable developer mode

toggle the "developer mode" switch in the top-right corner of the extensions page.

04

load unpacked

click "load unpacked" and select the folder you extracted. the extension icon will appear in your toolbar.

05

done

open discord in a tab, click the extension icon and you're good to go.

keep in mind: the folder you select must contain the manifest.json file directly — not nested inside another folder.
01

download

download the firefox .zip from the download page and extract it somewhere permanent.

02

open debugging page

open about:debugging#/runtime/this-firefox in your address bar.

03

load temporary add-on

click "load temporary add-on" and select the manifest.json file inside the extracted folder.

04

done

open discord in a tab, click the extension icon and you're good to go.

note for firefox: temporary add-ons are cleared when you close firefox. you'll need to reload the extension each time you restart the browser.

after installation

open

open discord in a tab

the extension needs an active discord.com tab to read your current session token.

click

click the extension icon

the popup will show your current session info and options to save, switch, verify and export.

save

save your first session

click "save current session" to add it to your vault. add a name or let it auto-generate one.
